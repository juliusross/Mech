# Product

## Register

product

## Users

Friends testing a browser-based mech game on desktop computers. The current implementation is a keyboard-and-mouse prototype with optional on-screen controls.

## Product Purpose

MECHVERSE is a mech test arena. The user approved private multiplayer rooms, starting with two players seeing each other's movement before shared combat and four-player validation.

## Brand Personality

The existing product uses a compact science-fiction cockpit HUD and straightforward action labels. Preserve that established tone for this feature.

## Anti-references

No specific external anti-reference has been selected. This feature extends the existing arena rather than introducing a marketing page or redesign.

## Design Principles

- Make joining a friend's room straightforward.
- State connection failures and feature limits clearly.
- Keep the arena and controls accessible while playing.
- Preserve solo play while multiplayer is developed.

## Accessibility & Inclusion

Use labeled native inputs, visible keyboard focus, text alongside pilot colors, and readable connection messages. No special accessibility standard has been requested; do not claim formal conformance.
